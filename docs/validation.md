## Colabで残っている検証

1. 本人の録音を登録し、生成音声を試聴する。書き起こしなし・ありの品質も確認する。
2. ノートブックの「20例×3回の測定」で音質・生成時間・GPUメモリを記録する。
3. 同じセッションで停止・再起動・準備セルの再実行を行い、音声が保持されることを確認する。新しいセッションでは再アップロードが必要なことも確認する。
4. Discordで参加・連投・スキップ・クリア・生成中の退出・無人退出・再接続を試す。
5. 待ち行列なしの投稿について `idle_first_packet_seconds` の平均・95パーセンタイル・最大を確認し、VCでも聞こえ始めを確認する。

測定していない項目は達成済みとせず、5秒超過もそのまま記録します。
